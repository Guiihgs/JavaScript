Operadores

Operadores Aritméticos

Usados para realizar cálculos matemáticos básicos e avançados.

  • + (Adição): Soma números ou concatena (junta) textos.
  • - (Subtração): Subtrai valores numéricos.
  • * (Multiplicação): Multiplica valores.
  • / (Divisão): Realiza a divisão.
  • % (Módulo): Retorna o resto de uma divisão inteira.
  • ** (Exponenciação): Eleva um número à potência de outro.

Operadores de Atribuição

Usados para atribuir valores a variáveis. Além do operador básico, existem atalhos que combinam operações com atribuição.

  • = : Atribui um valor. Ex: var idade = 25;
  • += : Soma o valor atual e atribui o resultado. Ex: x += 5 é o mesmo que x = x + 5.
  • -= : Subtrai o valor atual e atribui o resultado. Ex: x -= 5 é o mesmo que x = x - 5.

Operadores de Comparação

Comparam dois valores e retornam sempre um valor booleano: true (verdadeiro) ou false (falso).

  • > / <: Maior que / Menor que.
  • >= / <=: Maior ou igual a / Menor ou igual a.
  • == (Igualdade): Verifica se dois valores são iguais, mas pode causar conversões de tipo inesperadas.
  • === (Igualdade Estrita): Verifica se os valores e os tipos de dados são idênticos.
  • !== (Desigualdade Estrita): Verifica se os valores ou os tipos são diferentes.

Operadores Lógicos

Utilizados para combinar ou inverter condições e criar lógicas mais complexas.

  • ! (NÃO): Inverte o valor lógico. Transforma true em false e vice-versa.
  • && (E): Retorna verdadeiro apenas se ambas as condições forem verdadeiras.
  • || (OU): Retorna verdadeiro se pelo menos uma das condições for verdadeira.

Operadores Especiais

O JavaScript também possui operadores muito úteis para reduzir linhas de código e lidar com dados complexos ou nulos.

  • ? : (Ternário): Uma forma compacta de escrever if/else. Ex: condicao ? valor1(if) : valor2(else)
