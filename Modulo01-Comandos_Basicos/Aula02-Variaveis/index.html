Tipos de Variaveis

  • Number representa números, sejam inteiros ou com casas decimais. Inclui valores especiais como NaN (Not a Number) e Infinity.

    • NaN significa Not a Number (Não é um Número). Ele é gerado quando uma operação matemática não pode ser resolvida ou resulta em um valor inválido, como tentar multiplicar uma string por um número, ou dividir zero por zero

    • Infinity representa um número infinito ou um valor numérico maior do que qualquer outro que o JavaScript consiga armazenar. Ocorre geralmente quando você divide um número positivo por zero (ex: 10 / 0 resulta em Infinity) ou quando um cálculo excede o limite máximo permitido.

  • String representa textos criados entre aspas simples, duplas ou crases (ex: "Olá", 'JavaScript').

  • Boolean representa um valor lógico de verdadeiro ou falso (true ou false).

  • Null representa a ausência intencional de qualquer valor ou objeto.

  • Undefined representa o valor padrão de uma variável que foi declarada, mas ainda não teve um valor atribuído.

  • Object ao contrário dos primitivos, o tipo Object é uma coleção mutável de dados ou funcionalidades. Arrays, funções e datas são considerados subtipos de objetos na linguagem

    • Array é uma estrutura de dados que permite armazenar múltiplos valores (elementos) em uma única variável. Ele funciona como uma lista ordenada onde cada elemento ocupa uma posição específica, e você pode guardar itens de diferentes tipos (textos, números, objetos e até outros arrays)

  • Function é um bloco de código reutilizável projetado para executar uma tarefa específica ou calcular um valor. Ela atua como um "robô" ou "verbo": você a cria apenas uma vez e pode chamá-la de vários lugares do seu código, evitando repetição.
